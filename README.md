# AlignVelo
## Discription
<img width="4663" height="4454" alt="figure1" src="https://github.com/user-attachments/assets/a51f55bb-867a-47f7-b0c3-a09a0410f562" />

AlignVelo is a computational method designed for batch-consistent RNA velocity estimation.

## Installation
Clone this repository and install it via pip:

```bash
git clone https://github.com/yurouwang-rosie/AlignVelo.git
cd AlignVelo
pip install .
```
